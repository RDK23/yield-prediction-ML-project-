This project is a web-based system for predicting maize crop yield using geospatial and environmental data. It allows users to mark farm locations or draw farm boundaries on an interactive map and receive yield predictions generated by a trained machine learning model. The system also provides dashboards and analytics to visualize prediction trends and feature importance.

Project Structure (High Level)

Frontend: User interface, maps, dashboards, and analytics
Backend: Prediction API, data storage, and model inference
Modeling: Feature engineering and maize yield model training

Backend

Python

Flask (REST API)
SQLite (data storage)
Scikit-learn (machine learning model)
Pandas & NumPy (data processing)
Joblib (model persistence)

Frontend

React
Axios (API communication)
Leaflet & React-Leaflet (interactive maps)
Recharts (data visualization)
Data & Modeling
Remote sensing–derived vegetation indices (NDVI)
Weather and rainfall features
Supervised machine learning for yield prediction
